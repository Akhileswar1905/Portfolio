## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Akhileswar1905/portfolio-v2.git
cd portfolio-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

The portfolio will open at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder.
